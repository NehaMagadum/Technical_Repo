# PEP 8
PEP 8 is the official Python coding style guide. It explains how to write Python code in a clean, readable, and consistent way.
## Important Rules of PEP 8
1. Indentation   
• Use 4 spaces for indentation.  
• Avoid maxing tabs and spaces.
```
if True:
    print("Hello")
```
2. Variable Names   
• Use lowercase letters.  
• Separate words using underscores(_).
```
student_name = "Neha"
total_marks = 90
```
3. Function Names   
• Use lowercase letters with underscores.
```
def calculate_sum():
    pass
```
4. Class Names   
• Use PascalCase (each word starts with a capital letter).
```
class StudentDetails:
    pass
```
5. Line Length   
• Keep lines generally within 79 characters.  
• Break long lines into multiple lines.

6. Spaces   
• Use spaces around operators.
```
a = 10 + 20
```
7. Blank Lines   
• Use blank lines to separate functions and classes for better readability.

8. Comments   
• Write clear and meaningful comments.
```
# Calculate the total marks
total = 90
```
## Why PEP 8 important?
• Makes code easy to read.  
• Maintains consistency between developers.  
• Makes code easier to understand and maintain.  
• Helps developers follow standard Python practices.
