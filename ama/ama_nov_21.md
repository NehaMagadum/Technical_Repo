# AMA - Questions 21-Nov

## 1. what does `<html>` element defines while we writing html file

### Answer:

The `<html>` element is the root element of an HTML document. It contains all other HTML elements.

## 2. Difference display none and visibility hidden

### Answer:

- display: none - Hides the element and removes its space.
- visibility: hidden - Hides the element but keeps its space.

## 3. Difference between id selector and class selector

### Answer:

- ID (#): Used to identify a unique element.
- Class (.): Used to style multiple elements.

## 4. Difference between css and html

### Answer:

- HTML: Defines the structure and content of a webpage.
- CSS: Defines the styling and appearance of a webpage.

## 5. What is difference between sql and nosql

### Answer:

- SQL: Uses relational tables with structured data.
- NoSQL: Uses flexible formats like documents, key-value pairs, and graphs.

## 6. how can we bold a character in html

### Answer:

We can use the `<b>` or `<strong>` tag.  
Example: `<b>Hello</b>`

## 7. what are self closing tags in html

### Answer:

Tags that do not require a separate closing tag are called void elements.

Examples: `<br>`, `<hr>`, `<img>`, `<input>`.

## 8. When there are some content in a container how can we make the last element to be the first one using display flex

### Answer:

We can use the CSS order property to change the visual order of flex items.

## 9. What is the constructor in python

### Answer:

A constructor is a special method **init**() that initializes an object's attributes when an object is created.

## 10. What is the use of `<div>` tag

### Answer:

The `<div>` tag is a block-level container used to group HTML elements for styling and layout.

## 11. What is the difference between break, continue and pass

### Answer:

- break: Terminates the loop.
- continue: Skips the current iteration.
- pass: Does nothing; acts as a placeholder.

## 12. What is the time complexity for removing an element from a list

### Answer:

- Removing by index: O(n) in general.
- Removing by value: O(n).
- Removing the last element using pop(): O(1).

## 13. Difference between drop, truncate and delete

### Answer:

| DELETE                | TRUNCATE         | DROP                     |
| --------------------- | ---------------- | ------------------------ |
| Removes selected rows | Removes all rows | Removes the entire table |
| Supports WHERE        | No WHERE         | Removes table structure  |
| DML command           | DDL command      | DDL command              |

## 14. types of heading tags

### Answer:

HTML provides six heading tags, from `<h1>` to `<h6>`.

- `<h1>` – Largest/most important heading.
- `<h6>` – Smallest/least important heading.

## 15. What is "for else" in python

### Answer:

The else block executes after a for loop completes normally without encountering a break.

## 16. What are user agent

### Answer:

A User Agent is software that accesses and displays web content on behalf of users. A web browser acts as a user agent.
